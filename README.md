# Yuki Fuyutsuki

**LLMs · Reasoning · Autonomous Agents**

Research interests in the foundations of large language models, including transformer architectures, post-training, inference-time computation, and the mechanisms underlying complex reasoning.

I am particularly interested in agentic systems, persistent memory, planning, and the architectural challenges of reliable long-horizon autonomy.

### Research Interests

- **Language Models:** Transformer architectures, scaling laws, representation learning, post-training, and reinforcement learning.
- **Reasoning:** Inference-time scaling, search, process supervision, and verification.
- **Agent Systems:** Planning, tool use, memory architectures, and long-horizon execution.
- **Reliability:** Runtime verification, state consistency, failure recovery, and agent evaluation.
